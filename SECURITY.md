# Security policy

## Reporting a vulnerability

Report vulnerabilities privately by email to **security@sibylline.group**.

Do not open a public issue, pull request or discussion about a vulnerability,
and do not disclose it publicly before it is fixed. (Issues and discussions are
turned off on this repository in any case.)

Include, as far as you can:

- what the vulnerability is and what an attacker can do with it;
- the affected release tag or commit SHA, and your OS and architecture;
- the steps or a proof of concept that reproduce it;
- any logs or output that show it, with your own secrets removed;
- whether you have told anyone else, and any disclosure date you have in mind.

## What happens next

We acknowledge every report within 3 business days. We then confirm whether
the issue is a vulnerability, keep you informed while we fix it, and agree a
disclosure date with you.

## Supported versions

Only the latest release is supported. Fixes ship in a new release; earlier
releases are not patched.
